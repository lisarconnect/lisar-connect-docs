# L2TP/IPsec Setup

This guide explains the basic L2TP/IPsec setup flow for Lisar Connect profiles.

Lisar Connect can provide compatible L2TP/IPsec setup values for supported profiles. These values can be used with operating systems and clients that support L2TP/IPsec.

## Before you start

You need:

- A Lisar Connect account
- An active connection profile
- Access to the profile details page
- A device or operating system that supports L2TP/IPsec VPN setup

## Setup values

The profile details page may provide:

- Server / App Record
- Username
- Password
- IPsec PSK
- Routing information
- Entry and exit location details

Keep these values private.

## General setup flow

The exact steps depend on your operating system, but the general flow is:

1. Open your device VPN settings.
2. Add a new VPN connection.
3. Choose L2TP/IPsec if available.
4. Enter the server/app record from Lisar.
5. Enter the username from Lisar.
6. Enter the password from Lisar.
7. Enter the IPsec PSK from Lisar.
8. Save the VPN profile.
9. Connect.
