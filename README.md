# Lisar Connect Docs

Public setup notes and product documentation for Lisar Connect.

Lisar Connect helps users create VPN connection profiles for standard clients such as OpenVPN and compatible L2TP/IPsec setup.

No mandatory proprietary app.

## What Lisar Connect provides

- VPN connection profile creation
- OpenVPN `.ovpn` file download
- Compatible L2TP/IPsec setup values
- Entry and exit routing options
- Active VPN session visibility
- Connection history
- Dashboard-based profile management

## What Lisar Connect is not

Lisar Connect is not trying to replace OpenVPN or native VPN clients.

The goal is to remove VPN vendor lock-in around the service layer: profile creation, routing, credentials, active sessions, connection history, and setup visibility.

Users can connect with standard clients where supported.
